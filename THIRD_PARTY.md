# Third-party and inspiration notices

This repository contains no vendored browser adapter, extension, platform client, or third-party source code.

## Conceptual inspiration

The public project [X Hot Reply Copilot](https://github.com/JessiJCJingyi/x-hot-reply-copilot) prompted the high-level question of how a product account can identify public conversations and prepare human-reviewed responses. This repository uses a different Skill name, run contract, review model, response stances, schemas, scripts, examples, and document structure.

The referenced repository did not advertise an open-source license when this release candidate was prepared. Its files are not copied, redistributed, or licensed by this project. Contributors must not import material from it without separate permission.
